GitHub & Vercel Dağıtım Rehberi

Bu siteyi kendi alan adınızda veya ücretsiz Vercel linkinizde yayınlamak için aşağıdaki adımları takip edin:

  1. GitHub Deposu Açın: GitHub'da yeni bir repository (örn: crushers-agalar-lore) oluşturun.
  2. index.html Dosyası Ekle: Bu sayfanın tüm kodunu kopyalayın ve depoda index.html olarak kaydedin.
  3. Vercel'e Bağlayın: Vercel.com adresine GitHub hesabınızla giriş yapın, "Add New Project" seçip hiyerarşideki depoyu seçin.
  4. Deploy Et: Herhangi bir özel ayar yapmadan "Deploy" butonuna basın. Siteniz 10 saniye içinde canlıya alınacaktır!
Veritabanı Notu: Uygulama dahili olarak Firebase bulut veritabanına bağlıdır. Deploy ettikten sonra bile gruptaki herkesin yazdığı veriler ortak bulut sunucusunda anlık senkronize olmaya devam eder.
